# Screenshot gallery

Screenshots of the prototype, taken on 25 Sep 2026 with the live Bird feed and the 19 Aug–8 Sep 2026 sample. Desktop images are 1920×1200 and mobile images 1206×2622 (iPhone); all are 256-colour optimised PNGs. The interface is in Portuguese; every page has a PT/EN switch.
